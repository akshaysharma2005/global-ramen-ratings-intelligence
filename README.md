## 🌟 Overview

The **Global Ramen Ratings Intelligence** platform elevates instant ramen exploratory data analysis into a multi-dimensional sensory journey. Analyzing 2,577 curated ramen reviews from over 38 nations, it provides automated NLP flavor categorization, 3D manufacturer benchmarking landscapes, orthographic global rating maps, and a 4D chronological review evolution simulator.

## ✨ Features & Visual Dimensions

### 📊 1. 2D Sensory & Packaging Analytics
- **Dual-Axis Packaging Metrics**: Comparing review volume and average star rating across packaging formats (*Pack, Bowl, Cup, Tray, Box*).
- **Polar Flavor Radar Chart**: Mapping consumer quality perceptions across distinct flavor profiles (*Spicy/Chili, Seafood/Prawn, Tonkotsu/Rich Broth, Miso/Soy, Chicken, Beef*).
- **Brand Production Volume Rankings**: Quantifying market presence for top brands like Nissin, Nongshim, Maruchan, and Indomie.

### 🌐 2. 3D Brand Morphospace & Planetary Geography
- **3D Strategic Brand Landscape**:
  - **X-Axis**: Review Count (Catalog Breadth)
  - **Y-Axis**: Average Star Rating (Perceived Quality)
  - **Z-Axis**: Top 10 Global Accolades (Elite Recognition)
  - Color-coded continuous grading identifying standout producers.
- **3D Orthographic Earth Globe**: Interactive globe projecting national ramen quality benchmarks.

### ⏳ 3. 4D Chronological Review Evolution
- **4D Hyper-Dimensional Projection**:
  - **Dim 1 (X)**: Review Sequence Number (Time)
  - **Dim 2 (Y)**: Star Rating (0-5)
  - **Dim 3 (Z)**: Nomenclature / Flavor Complexity (Title Length)
  - **Dim 4 (Color)**: Packaging Format
  - **Dim 5 (Size)**: Star Rating
  - **Dim 6 (Time / Frame Animation)**: Review Eras 1 through 6
- Trace the historical shift from simple cup noodles to artisanal gourmet ramen packs.

### 🍲 4. Personalized Flavor & Discovery Engine
- Dynamic filtering across flavor profiles, packaging formats, and origin countries with curated recommendation cards.

## 🚀 Getting Started

### Installation

1. **Clone the repository**:
   ```bash
   git clone https://github.com/akshaysharma2005/global-ramen-ratings-intelligence.git
   cd global-ramen-ratings-intelligence
   ```

2. **Install dependencies**:
   ```bash
   pip install -r requirements.txt
   ```

3. **Run the Dashboard**:
   ```bash
   streamlit run app.py
   ```

4. Open `http://localhost:8501`.
